## 【推荐体验路径】（5步走，带你逛完核心功能）

### 第1步：看板总览

登录后首先看到的是**「看板」**——这是你的生活总览。

顶部的**「今日关注」**是核心区域，四张卡片一目了然：
- **已过期**（红色）：多少件物品已经过期了
- **30天内**（橙色）：多少件30天内要到期
- **90天内**（黄色）：多少件90天内需要注意
- **库存不足**（蓝色）：多少件食材该补货了

点击任意数字卡片，可直接跳转到对应模块查看明细。

往下滚动还能看到：
- 健康快照（最新体重/血糖）
- 本月提醒（待办事项）
- 各模块分类统计饼图
- 七日活动趋势图

---

### 第2步：临期提醒详情

点击**「今日关注」**中**「30天内」**卡片 → 跳转到冰箱库存模块，按临期排序展示。

随便点开一项食材，试试这些操作：
- 查看详情：保质期、存放位置、剩余数量
- 点击**「处理」**按钮：标记为已食用后，物品会移到历史归档
- 点击**「编辑」**按钮：修改数量、保质期等信息

---

### 第3步：护肤品管理

左侧导航点击**「护肤品」** → 查看所有护肤品的保质期状态。

每一张卡片上都有：
- 到期标签（已过期/还剩X天）
- 剩余用量进度条
- 品牌和分类

试试这些操作：
- 点击**「+ 添加护肤品」** → 弹出新增表单
- 试试右侧的 **🎤 语音输入按钮**（需Chrome浏览器），说"精华液 1瓶"，会自动识别名称和数量
- 点击任意卡片 → 查看15+详细字段（使用感、回购意愿、适合季节、肤质等）
- 切换**「已归档」**标签 → 查看用完的空瓶记录

---

### 第4步：健康管理

左侧导航点击**「健康管理」** → 进入日历视图。

- 绿色圆点：当天有健康记录
- 粉色标记：经期

试试这些操作：
- 点击任意日期 → 添加或编辑当天的健康数据（体重、血糖、心情、天气等）
- 切换**「列表视图」** → 按时间顺序查看所有记录
- 观察体重趋势：最近30天体重从51.5kg降到50.8kg，经期有小幅波动

---

### 第5步：自由探索

- **生活用品**：左侧导航点击 → 看看洗衣液、纸巾还剩多少
- **日常日志**：左侧导航点击 → 翻看最近10天的日记，天气和心情都有记录
- **本月提醒**：看板页往下滚 → 查看本月待办，点击可以直接编辑

想体验从零开始的感觉：
1. 点击右上角头像 → 退出登录
2. 点击**「注册」** → 创建一个新账号
3. 登录后点击**「一键导入示例数据」** → 快速填充演示数据
4. 右下角有**新手任务清单**，跟着任务一步步熟悉功能

## 【功能清单】

| 模块 | 功能点 |
|------|--------|
| 护肤品管理 | 15+字段、临期提醒、归档管理、空瓶记录 |
| 冰箱库存 | 保质期管理、库存预警、位置标记、处理/归档 |
| 生活用品 | 分类管理、补货提醒、价值统计 |
| 健康管理 | 体重/血糖/经期/心情日历、列表视图 |
| 日常日志 | 每日记录、天气心情、最近趋势 |
| 可视化看板 | 到期提醒总览、健康快照、本月提醒、分类统计 |
| 语音输入 | 支持中文语音识别、智能解析名称+数量 |
| 新手引导 | 任务清单 + 一键导入示例数据 |
