# 随序 - Render 部署指南

---

## 准备工作

1. 注册 Render 账号：https://render.com/ （可用 GitHub 登录）
2. 将项目代码推送到 GitHub 仓库

---

## 部署步骤

### 第一步：新建 Web Service

1. 登录 Render，点击右上角 **「New +」** → **「Web Service」**
2. 选择 **「Public Git repository」** 或连接你的 GitHub 仓库
3. 填入仓库地址，点击 **「Continue」**

---

### 第二步：配置服务

在设置页面填入以下配置：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| Name | `sui-xu` | 服务名称，会影响你的访问域名 |
| Region | `Singapore` | 选离中国近的节点，访问更快 |
| Runtime | `Node` | Node.js 环境 |
| Build Command | `npm install` | 安装依赖 |
| Start Command | `node server.js` | 启动服务 |
| Plan | `Free` | 免费版（比赛够用） |

---

### 第三步：环境变量（可选）

点击 **「Advanced」** → **「Add Environment Variable」**，添加：

| Key | Value | 说明 |
|-----|-------|------|
| `PORT` | `10000` | Render 默认端口（代码中已兼容，可不设） |
| `JWT_SECRET` | `sui-xu-jwt-secret-2026` | JWT 加密密钥，建议改为随机字符串 |
| `NODE_ENV` | `production` | 生产环境标记 |

> 注意：JWT_SECRET 一定要改，不然有安全风险。随便填一串复杂的随机字符串就行。

---

### 第四步：部署

点击 **「Create Web Service」** 按钮。

等待 2-3 分钟，部署完成后会得到一个 URL，类似：
```
https://sui-xu.onrender.com
```

直接在浏览器打开就能访问了。

---

### 第五步：初始化演示数据（可选）

部署完成后，如果需要演示数据，按以下步骤操作：

1. 在 Render 后台进入你的服务
2. 点击顶部 **「Shell」** 标签
3. 在命令行中输入：
   ```bash
   node seed.js
   ```
4. 等待执行完成，看到「数据填充完成」的提示就好了

> 演示账号：用户名 `demo`，密码 `demo123456`

---

## 使用 render.yaml 一键部署（可选）

项目根目录已包含 `render.yaml` 配置文件，也可以通过以下方式快速部署：

1. 将代码推送到 GitHub
2. 在 Render 中选择 **「Blueprint」** 方式导入
3. 选择仓库和 `render.yaml` 文件
4. 一键完成部署配置

---

## 注意事项

1. **免费版休眠问题**
   - Render 免费版 15 分钟无请求会休眠
   - 首次打开可能需要等几十秒唤醒（正常现象）
   - 唤醒后访问速度正常

2. **数据持久化**
   - SQLite 数据库文件存在实例本地磁盘
   - 重新部署会重置数据（因为实例重建了）
   - **比赛期间不要重新部署，数据就不会丢**

3. **自定义域名（可选）**
   - Render 支持绑定自定义域名
   - 在服务设置的 **「Custom Domains」** 中添加即可
   - 需要在域名服务商配置 DNS 解析

4. **日志查看**
   - Render 后台 **「Logs」** 标签可以查看服务日志
   - 报错、启动信息都在这里

---

## 常见问题

**Q: 部署失败怎么办？**
A: 查看 Logs 标签里的错误信息，常见原因：
- 依赖安装失败 → 检查 package.json
- 端口被占用 → 确保用的是 process.env.PORT 或 10000
- 代码报错 → 本地先跑通再部署

**Q: 数据丢了怎么办？**
A: 重新跑 `node seed.js` 就能恢复演示数据。如果是用户自己的数据，建议定期备份 `life.db` 文件。

**Q: 访问很慢？**
A: 免费版节点在海外，第一次打开需要唤醒，多等一会儿就好。正式使用可以升级付费版或选更近的节点。
